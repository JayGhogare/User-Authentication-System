# 🔐 Simple User Authentication System

A basic Python project that simulates a login system using username and password validation.


## 📌 Features
- Username verification
- Password (PIN) authentication
- Simple conditional logic
  \
- Beginner-friendly project


## 💻 Tech Used
- Python

## 🧠 How It Works
- User enters username and password
- System checks if credentials match stored values
- If correct → Login Successful
- If incorrect → Error message
